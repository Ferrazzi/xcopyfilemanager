Google Drive access

Accesso a Google Drive

Google Drive is optional. Xcopy asks for authorization only when you choose to connect a Google account. The requested Drive permission is used to let you browse, create, download, upload, rename, move and delete files and folders as part of the file-manager features you explicitly use.

Google Drive è facoltativo. Xcopy richiede l'autorizzazione solo quando scegli di collegare un Account Google. Il permesso Drive viene usato per consentirti di sfogliare, creare, scaricare, caricare, rinominare, spostare ed eliminare file e cartelle tramite le funzioni del file manager che utilizzi esplicitamente.

Limited Use. Xcopy File Manager uses information obtained through Google APIs in accordance with the Google API Services User Data Policy and its Limited Use requirements. Google Drive file content is not used for advertising.

Uso limitato. Xcopy File Manager utilizza le informazioni ottenute tramite le API Google nel rispetto della Google API Services User Data Policy e dei relativi requisiti Limited Use. Il contenuto dei file di Google Drive non viene utilizzato per la pubblicità.
