Google Drive and privacy

Google Drive e privacy

Google Drive is optional and is connected only after the user authorizes a Google account. Xcopy uses Drive access to provide file-manager operations requested by the user.

Google Drive è facoltativo e viene collegato solo dopo che l'utente autorizza un Account Google. Xcopy usa l'accesso a Drive per fornire le operazioni da file manager richieste dall'utente.

Limited Use. Information obtained through Google APIs is handled in accordance with the Google API Services User Data Policy and its Limited Use requirements.

Uso limitato. Le informazioni ottenute tramite le API Google vengono gestite nel rispetto della Google API Services User Data Policy e dei relativi requisiti Limited Use.
