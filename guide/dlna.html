DLNA / UPnP

Automatically discover media servers on the network and browse their read-only content.

On this pageAutomatic discoveryBrowsingStreaming and copyRead-only

Automatic discovery

Expand DLNA. Xcopy sends SSDP/UPnP discovery on the local network and lists compatible Media Servers. No IP or credentials are required.

Browsing

Expand a server to navigate folders published by its ContentDirectory service. Audio, video and images are recognized from the resources the server exposes.

Streaming and copy

Audio/video can be streamed; images and supported files can be opened or copied to the opposite panel.

Read-only

ImportantDLNA is not a file-management protocol. Xcopy therefore does not offer delete, rename, move or upload to the DLNA server.

DLNA / UPnP

Scoprire automaticamente Media Server in rete e navigarne i contenuti in sola lettura.

In questa paginaRicerca automaticaNavigazioneStreaming e copiaSola lettura

Ricerca automatica

Espandi DLNA. Xcopy invia una ricerca SSDP/UPnP sulla rete locale e mostra i Media Server compatibili trovati. Non devi inserire IP o credenziali.

Navigazione

Espandi un server per navigare le cartelle pubblicate dal servizio ContentDirectory. Audio, video e immagini vengono riconosciuti in base alle risorse offerte dal server.

Streaming e copia

Audio/video possono essere riprodotti in streaming; immagini e file supportati possono essere aperti o copiati nel pannello opposto.

Sola lettura

ImportanteDLNA non è un protocollo di gestione file. Xcopy quindi non offre elimina, rinomina, sposta o upload verso il server DLNA.
