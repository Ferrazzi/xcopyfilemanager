App backup and restore

Save Xcopy settings, Notes and saved network connections so they can be restored later.

On this pageWhat is includedBackup passwordAutomatic backupRestore

What is included

A manual backup includes supported settings, Notes and saved SMB, FTP, SSH/SFTP and WebDAV connection credentials. Google Drive authorization and Vault recovery information are not exported.

Backup password

When you export a backup from Settings, Xcopy asks you to choose a backup password. Saved network passwords are encrypted with it and are never written to the backup in plain text. Keep the backup password somewhere safe: Xcopy does not store it and cannot recover it for you.

Automatic backup

Automatic App backup can save settings and Notes periodically without asking for a password. For security, automatic backups do not include saved network passwords.

Restore

Select the folder containing the backup. If the backup contains encrypted credentials, enter the same backup password used during export. Older backups that did not contain passwords remain supported.

Backup e ripristino dell’app

Salva impostazioni, Note e connessioni di rete di Xcopy per poterle ripristinare in seguito.

In questa paginaCosa includePassword del backupBackup automaticoRipristino

Cosa include

Il backup manuale include le impostazioni supportate, le Note e le credenziali salvate delle connessioni SMB, FTP, SSH/SFTP e WebDAV. L’autorizzazione di Google Drive e le informazioni di recupero delle Cassaforti non vengono esportate.

Password del backup

Quando esporti un backup dalle Impostazioni, Xcopy ti chiede di scegliere una password del backup. Le password delle connessioni vengono cifrate con questa password e non vengono mai scritte in chiaro nel file. Conservala in un posto sicuro: Xcopy non la salva e non può recuperarla.

Backup automatico

Il Backup app automatico può salvare periodicamente impostazioni e Note senza chiedere una password. Per sicurezza, i backup automatici non includono le password delle connessioni salvate.

Ripristino

Seleziona la cartella che contiene il backup. Se il backup contiene credenziali cifrate, inserisci la stessa password usata durante l’esportazione. I vecchi backup che non contenevano password restano compatibili.
