Troubleshooting

Quick checks when a source, server or operation does not behave as expected.

On this pageNetworkXcopy serversStorage and USBVault

Network

  • Confirm devices are on the same LAN.
  • Check local-network permission when Android requires it.
  • For SMB/FTP/SSH verify IP/host, port and credentials.
  • For DLNA collapse/expand the node to run discovery again.

Xcopy servers

  • Check the foreground notification: Android must show it while the service is active.
  • Use Quick Settings or launcher shortcuts to toggle without opening Xcopy.
  • If a tile is missing, add it from Android's tile editor or the Settings request helper.

Storage and USB

  • For protected folders verify Shizuku/root or SAF authorization.
  • Do not disconnect USB during active operations.
  • If a list does not show a change immediately, use Refresh or leave and re-enter the folder.

Vault

  • Biometrics are per-vault, not global.
  • Keep recovery codes outside the device.
  • If all recovery credentials are lost, encryption has no bypass.

Risoluzione problemi

Controlli rapidi quando una sorgente, un server o un’operazione non funziona come previsto.

In questa paginaReteServer XcopyStorage e USBCassaforte

Rete

  • Verifica che i dispositivi siano sulla stessa LAN.
  • Controlla il permesso rete locale quando richiesto da Android.
  • Per SMB/FTP/SSH verifica IP/host, porta e credenziali.
  • Per DLNA espandi di nuovo il nodo per rilanciare la ricerca.

Server Xcopy

  • Controlla la notifica foreground: se il servizio è attivo, Android deve mostrarla.
  • Usa Quick Settings o shortcut launcher per ON/OFF senza aprire Xcopy.
  • Se un riquadro non compare, aggiungilo dal pannello Modifica riquadri Android o dalla richiesta in Impostazioni.

Storage e USB

  • Se una cartella è protetta, verifica Shizuku/root o autorizzazione SAF.
  • Non scollegare USB durante operazioni attive.
  • Se una lista non mostra subito una modifica, usa Aggiorna oppure esci e rientra nella cartella.

Cassaforte

  • La biometria è per singola cassaforte, non globale.
  • Conserva il codice di recupero fuori dal dispositivo.
  • Se perdi tutte le credenziali di recupero non è previsto un bypass della cifratura.
