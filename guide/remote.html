Remote connections

Use Xcopy with SMB/NAS, FTP, SSH/SFTP, WebDAV/cloud and other network sources.

On this pageSame local-file workflowRefreshCredentials

Same local-file workflow

After configuration, remote sources appear in the tree and can be used as source or destination in dual-panel mode. Copy, move, rename and delete are available when protocol and server permissions allow.

Refresh

After successful copies, renames or deletions, Xcopy refreshes the affected lists. Speed depends on your network and the server being used.

Credentials

Saved credentials are used only to connect to configured sources. Protect access to Xcopy if the device is shared with other people.

Connessioni remote

Usare Xcopy con SMB/NAS, FTP, SSH/SFTP, WebDAV/cloud e altre sorgenti di rete.

In questa paginaStesso flusso dei file localiAggiornamentoCredenziali

Stesso flusso dei file locali

Dopo la configurazione, le sorgenti remote si navigano nel tree e possono essere usate come sorgente o destinazione nel doppio pannello. Copia, sposta, rinomina ed elimina sono disponibili quando il protocollo e i permessi del server lo consentono.

Aggiornamento

Dopo copie, rinomine o eliminazioni riuscite, Xcopy aggiorna le liste interessate. La velocità dipende dalla rete e dal server utilizzato.

Credenziali

Le credenziali salvate vengono usate solo per collegarsi alle sorgenti configurate. Proteggi l’accesso a Xcopy se il dispositivo è condiviso con altre persone.
