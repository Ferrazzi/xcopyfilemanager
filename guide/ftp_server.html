Built-in FTP server

Turn the Android device into an FTP server reachable on the local network.

On this pageStart and stopConfigurationSupported operationsFTP is not encrypted

Start and stop

Expand FTP in the tree. FTP Server is the local node: tap for ON/OFF; long-press to configure. While active, its subtitle shows ftp://IP:port.

Configuration

Set port, username, password, shared folder, read-only mode and auto-start. The shared root confines paths visible to clients.

Supported operations

Browsing, upload/download, create/delete/rename and transfer resume are available in passive mode when enabled by configuration.

FTP is not encrypted

WarningClassic FTP does not encrypt credentials or data. Use SSH/SFTP on untrusted networks.

Server FTP interno

Trasformare il dispositivo in un server FTP accessibile dalla rete locale.

In questa paginaAvvio e arrestoConfigurazioneOperazioni supportateFTP non cifra

Avvio e arresto

Espandi FTP nel tree. Server FTP è il nodo locale: tap per ON/OFF; pressione lunga per configurare. Quando attivo, il sottotitolo mostra l’indirizzo ftp://IP:porta.

Configurazione

Puoi impostare porta, utente, password, cartella condivisa, modalità sola lettura e avvio automatico. La radice condivisa limita i percorsi accessibili dal client.

Operazioni supportate

Navigazione, upload/download, crea/elimina/rinomina e ripresa trasferimenti sono disponibili in modalità passiva quando abilitati dalla configurazione.

FTP non cifra

AttenzioneFTP classico non cifra credenziali o dati. Per reti non fidate usa il server SSH/SFTP.
