Hidden files and sorting

Control what appears and in which order, independently for each panel.

On this pageShow hiddenSortPer-panel memory

Show hidden

The button is always named Show hidden. A crossed-eye icon means hidden files and folders are filtered. A normal eye means they are visible.

The filter applies to both files and folders, and the list refreshes when you change this option.

Sort

The Sort popup can order files by Name, Size, Extension or Date, ascending/descending. Folder order is configured separately.

Per-panel memory

Sorting choices are stored independently for left and right panels.

File nascosti e ordinamento

Controlla cosa appare nella lista e in quale ordine, separatamente per pannello.

In questa paginaMostra nascostiOrdinaMemoria per pannello

Mostra nascosti

Il pulsante si chiama sempre Mostra nascosti. Quando l’icona è un occhio sbarrato, file e cartelle nascosti vengono filtrati. Quando l’occhio è normale, vengono visualizzati.

Il filtro riguarda sia file sia cartelle e la lista viene aggiornata quando cambi questa opzione.

Ordina

Il popup Ordina permette di ordinare i file per Nome, Dimensione, Estensione o Data, con direzione ascendente/discendente. Le cartelle hanno una scelta separata, così puoi ad esempio tenere cartelle per nome e file per data.

Memoria per pannello

Le scelte di ordinamento sono memorizzate indipendentemente nel pannello sinistro e destro.
