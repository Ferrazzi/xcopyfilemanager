Apps and USB devices

Manage installed APKs and removable storage from the tree.

On this pageApps nodeUSBSafe removal

Apps node

The Apps node shows installed/system applications with icon and package name. Where Android allows, copy the APK like a file. Some system apps use split APKs; Xcopy handles what is actually accessible.

USB

When you connect USB storage, open the USB node in the tree. If Android asks for permission, confirm it so Xcopy can read and manage the files.

Safe removal

Do not disconnect storage while a copy or background operation is still running.

App e dispositivi USB

Gestire APK installati e memorie rimovibili dal tree.

In questa paginaNodo AppUSBRimozione sicura

Nodo App

Il nodo App mostra applicazioni installate e di sistema con icona e package name. Dove Android lo consente puoi copiare l’APK come un file. Alcune app di sistema possono avere più split APK: Xcopy gestisce ciò che è effettivamente accessibile.

USB

Quando colleghi una memoria USB, apri il nodo USB nel tree. Se Android richiede un’autorizzazione, confermala per permettere a Xcopy di leggere e gestire i file.

Rimozione sicura

Non scollegare una memoria mentre una copia o un’operazione in background è ancora in corso.
