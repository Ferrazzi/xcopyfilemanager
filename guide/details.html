Details, sizes and counts

Details computes real totals for folders and mixed selections.

On this pageOne itemMultiple itemsBackground calculation

One item

For a file it shows size, type/path where available, total file/folder counts and Modified date/time. For a folder, size is the recursive sum of contained files.

Multiple items

With multiple files/folders selected Xcopy shows selected item count, combined size, Total files and Total folders. Modified date is omitted because there is no single meaningful value.

Background calculation

Large folders are scanned in the background to keep the UI responsive. Remote sources can take longer and depend on metadata exposed by the protocol.

Folder countThe total includes scanned subfolders; the selected folder itself is treated as a container, not a file.

Dettagli, dimensioni e conteggi

Mostra dettagli calcola valori reali anche per cartelle e selezioni miste.

In questa paginaUn singolo elementoPiù elementiCalcolo in background

Un singolo elemento

Per un file mostra dimensione, tipo/percorso quando disponibili, numero totale di file/cartelle e Modifica con data e ora. Per una cartella la dimensione è la somma ricorsiva di tutti i file contenuti.

Più elementi

Con più file/cartelle selezionati Xcopy mostra il numero di elementi selezionati, la dimensione totale, File totali e Cartelle totali. La data di modifica viene omessa perché non avrebbe un unico valore significativo.

Calcolo in background

Le cartelle grandi vengono analizzate in background per non bloccare l’interfaccia. Sorgenti remote possono richiedere più tempo e dipendono dalle informazioni che il protocollo espone.

Conteggio cartelleIl totale include le sottocartelle analizzate; la cartella selezionata viene trattata come contenitore, non come file.
