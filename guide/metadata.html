Audio and video metadata

Read and edit embedded tags without unnecessarily re-encoding media.

On this pageOpening the editorAudioVideoBefore saving

Opening the editor

Long-press a compatible audio/video file and choose Edit metadata. Xcopy shows readable fields and enables edits only when the format has a safe writer.

Audio

Supported formats can edit title, artist, album, album artist, composer, year, track, genre, comment and artwork. Audio files with embedded artwork show the cover directly in the file list.

Video

For writable containers Xcopy updates supported tags without transcoding. Formats without a safe writer open in metadata view-only mode.

Before saving

If Time Machine is enabled and applicable, it can preserve a previous version before the change. Still keep backups of important media.

Metadati audio e video

Leggere e modificare tag incorporati senza ricodificare inutilmente i contenuti.

In questa paginaAprire l’editorAudioVideoPrima di salvare

Aprire l’editor

Tieni premuto un file audio/video compatibile e scegli Modifica metadati. Xcopy mostra i campi leggibili e abilita la modifica solo quando il formato ha un writer sicuro.

Audio

Nei formati supportati puoi gestire titolo, artista, album, artista album, compositore, anno, traccia, genere, commento e copertina. I file audio con artwork incorporato mostrano la copertina direttamente nella lista file.

Video

Per contenitori scrivibili Xcopy modifica i tag supportati senza transcodifica. Formati privi di writer sicuro vengono aperti in sola visualizzazione dei metadati.

Prima di salvare

Se Time Machine è attivo e applicabile, può conservare una versione precedente prima della modifica. Mantieni comunque una copia dei file importanti.
