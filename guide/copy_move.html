Copying, moving and duplicating

Use the dual-panel workflow to make the destination clear before starting.

On this pageCopy between panelsMoveDuplicateList refresh

Copy between panels

  1. Open the destination folder in the destination panel.
  2. Return to the source panel.
  3. Select one or more files/folders.
  4. Tap Copy. Verify source and destination when a confirmation dialog is shown.

Move

Move follows the same flow but removes originals after a successful transfer. On remote protocols Xcopy may safely perform copy + delete.

Duplicate

Duplicate creates another copy in the same location with a non-conflicting name. Large folders may take time.

List refresh

When an operation finishes, the affected panels refresh automatically. Some remote sources may take a few seconds to show changes; use Refresh if you need to reload the folder.

Copiare, spostare e duplicare

Il flusso a doppio pannello rende chiara la destinazione prima di avviare l’operazione.

In questa paginaCopia tra pannelliSpostaDuplicaAggiornamento liste

Copia tra pannelli

  1. Nel pannello di destinazione apri la cartella in cui vuoi mettere i file.
  2. Torna al pannello sorgente.
  3. Seleziona uno o più file/cartelle.
  4. Premi Copia. Controlla sorgente e destinazione nel dialog quando previsto.

Sposta

Sposta usa lo stesso schema ma rimuove gli originali dopo il trasferimento riuscito. Su protocolli remoti Xcopy può dover eseguire copia + eliminazione in modo controllato.

Duplica

Duplica crea una seconda copia nella stessa posizione con un nome non in conflitto. Per cartelle grandi l’operazione può richiedere tempo.

Aggiornamento liste

Al termine di un’operazione i pannelli interessati vengono aggiornati automaticamente. Su alcune sorgenti remote l’aggiornamento può richiedere qualche secondo; se necessario usa Aggiorna per rileggere il contenuto.
