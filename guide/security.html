Security and privacy

How Xcopy handles credentials, vaults, local network and background services.

On this pageEncryption and recoveryNetwork serversBackupsAndroid permissions

Encryption and recovery

Vaults must not have backdoors. Password and recovery code are per-vault; biometrics use separate Keystore keys.

Network servers

Wi‑Fi, FTP and SSH/SFTP expose files only while active. Android requires foreground notifications for persistent services. FTP is unencrypted; SFTP is encrypted.

Backups

Backups must not export secrets explicitly excluded by components. Always consider where backups are stored and who can access them.

Android permissions

Xcopy requests permissions in relation to the function used: local network for discovery/servers, microphone when recording audio notes, storage access according to source type. Advanced functions must remain compatible with Google Play policies.

Sicurezza e privacy

Come Xcopy tratta credenziali, cassaforti, rete locale e servizi in background.

In questa paginaCifratura e recuperoServer di reteBackupPermessi Android

Cifratura e recupero

Le cassaforti non devono avere backdoor. Password e codice di recupero sono indipendenti per cassaforte; la biometria usa chiavi Keystore separate.

Server di rete

Wi‑Fi, FTP e SSH/SFTP espongono file solo mentre sono attivi. Android richiede notifiche foreground per servizi persistenti. FTP non cifra il traffico; SFTP sì.

Backup

I backup non devono esportare in chiaro segreti esplicitamente esclusi dai componenti. Controlla sempre dove salvi un backup e chi può accedervi.

Permessi Android

Xcopy richiede permessi in relazione alla funzione usata: rete locale per discovery/server, microfono quando registri audio in una nota, accessi storage secondo il tipo di origine. Le funzioni avanzate devono restare coerenti con le policy Google Play.
