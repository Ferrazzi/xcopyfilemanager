Multi-selection

Work on multiple files and folders with a single command.

On this pageBuilding a selectionMenus and toolbarRemote sources

Building a selection

Select the desired items in the same panel. Compatible actions use the entire selection, including mixed files and folders.

Menus and toolbar

With multiple selected items, Details computes combined totals; copy/move/delete/share process the whole group. Actions invalid for read-only sources are disabled or rejected.

Remote sources

Multi-selection is also available on many remote sources. Write support depends on protocol and server permissions.

Selezione multipla

Come lavorare su più file e cartelle nello stesso comando.

In questa paginaCreare la selezioneMenu e barraSorgenti remote

Creare la selezione

Seleziona gli elementi desiderati nello stesso pannello. Le azioni compatibili usano l’intera selezione, inclusi file e cartelle mescolati.

Menu e barra

Quando sono selezionati più elementi, Mostra dettagli calcola il totale complessivo; copia/sposta/elimina/condividi elaborano l’intero gruppo. Le azioni non valide per una sorgente sola lettura vengono disabilitate o rifiutate.

Sorgenti remote

La selezione multipla è disponibile anche su molte sorgenti remote. La disponibilità di scrittura dipende dal protocollo e dai permessi del server.
