Built-in viewers and editors

Open common formats without leaving Xcopy and use menus consistent with the app.

On this pageText and codeImages, audio and videoPDF and HexDatabases

Text and code

Edit supported text/source files. Before saving, Time Machine can capture the previous version when enabled and the item is not excluded.

Images, audio and video

The image viewer supports fullscreen, zoom and navigation among folder images. Audio/video can be played internally, including compatible remote streams.

PDF and Hex

PDF viewer/editor and Hex Viewer/Editor use Xcopy-style menus; editing depends on source writability.

Databases

SQLite Database Explorer/Editor shows structure/data and can edit supported databases. For Microsoft Access databases you can open supported MDB/ACCDB files, browse tables and data, and use the tools available for the opened file.

Viewer ed editor integrati

Aprire i formati comuni senza uscire da Xcopy e usare menu coerenti con il resto dell’app.

In questa paginaTesto e codiceImmagini, audio e videoPDF e HexDatabase

Testo e codice

Modifica file testuali e sorgenti supportati. Prima di salvare, Time Machine può catturare una versione precedente se è attivo e l’elemento non è escluso.

Immagini, audio e video

Il visualizzatore immagini supporta fullscreen, zoom e navigazione tra immagini della cartella. Audio e video possono essere riprodotti internamente, inclusi flussi remoti compatibili.

PDF e Hex

Viewer/editor PDF e Hex Viewer/Editor usano menu integrati nello stile Xcopy; le operazioni di modifica dipendono dalla scrivibilità della sorgente.

Database

SQLite Database Explorer/Editor permette di vedere struttura e dati e modificare database supportati. Per i database Microsoft Access puoi aprire file MDB/ACCDB supportati, consultare tabelle e dati e usare gli strumenti disponibili per il file aperto.
