Settings

Global Xcopy preferences: language, appearance, security, Time Machine, backup and more.

On this pageLanguage and themeFile behaviorTime MachineQuick Settings and servicesVersion

Language and theme

Xcopy's selected language controls the UI, Guide and dynamic launcher shortcuts. Theme can follow system/light/dark according to available options.

File behavior

Configure Trash, location restore, APK handling and other navigation preferences. Per-vault options are not global: manage them by long-pressing each vault in the tree.

Time Machine

Time Machine is off by default. Settings lets you enable/configure it and manage file/folder exclusions.

Quick Settings and services

The dedicated section can ask Android to add Xcopy Quick Settings tiles. Actual insertion requires user confirmation.

Version

The Version card at the bottom of Settings shows the installed Xcopy version.

Impostazioni

Preferenze globali di Xcopy: lingua, aspetto, sicurezza, Time Machine, backup e altro.

In questa paginaLingua e temaComportamento fileTime MachineRiquadri rapidi e serviziVersione

Lingua e tema

La lingua selezionata dentro Xcopy controlla l’interfaccia, la Guida e i collegamenti rapidi dinamici. Il tema può seguire sistema/chiaro/scuro secondo le opzioni disponibili.

Comportamento file

Configura Cestino, ripristino della posizione, gestione APK e altre preferenze di navigazione. Le opzioni relative alle singole cassaforti non sono globali: si gestiscono tenendo premuta la cassaforte nel tree.

Time Machine

Time Machine è disattivato di default. Dalle Impostazioni puoi abilitarlo, configurarlo e gestire le esclusioni di file/cartelle.

Riquadri rapidi e servizi

La sezione dedicata può richiedere ad Android l’aggiunta dei Quick Settings Xcopy. L’effettivo inserimento richiede conferma utente.

Versione

In fondo alle Impostazioni la card Versione mostra la versione installata.
