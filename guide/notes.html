Notes manager

Category-based notes with text, photos, audio and file references on the same page.

On this pageList and categoriesBlock editorImagesAudioInsert into Notes from file managerExport, share and backup

List and categories

Open ⋮ → Notes. The side menu always shows All notes and Trash; other rows are created only from categories actually used. Each row shows a note count.

Long-press a category to remove it and move its notes to Trash. In Trash, use Empty trash for permanent deletion.

Block editor

A note is a page of ordered blocks: text, library images, camera photos, imported audio, audio recordings and file references. Each block has its own menu for moving/removing it.

Images

Tap a photo for fullscreen view. From the block menu rotate left/right. Xcopy stores orientation without recompressing the original image.

Audio

Play changes to Stop during playback and returns to Play at completion/error. Starting a second audio stops the previous one.

Insert into Notes from file manager

Long-press a file and choose Insert into Notes: text → text block; images → image block; audio → audio block; other files → path/reference. Create a new note or choose an existing one.

Export, share and backup

Notes can be exported/shared; multimedia export preserves block order. Xcopy backups include notes and their private media.

Gestore Note

Note organizzate per categorie con testo, foto, audio e riferimenti a file nello stesso foglio.

Elenco e categorie

Apri ⋮ → Note. Il menu laterale mostra sempre Tutte le note e Cestino; le altre voci nascono dalle categorie realmente usate. Ogni voce mostra il conteggio delle note.

Tenendo premuta una categoria puoi eliminarla: le sue note vengono spostate nel Cestino. Da Cestino puoi usare Svuota cestino per cancellazione definitiva.

Editor a blocchi

Una nota è una pagina composta da blocchi ordinati: testo, immagini dalla libreria, foto dalla fotocamera, audio importato, registrazioni audio e riferimenti a file. Ogni blocco ha il proprio menu per spostarlo o rimuoverlo.

Immagini

Tocca una foto nella nota per aprirla a tutto schermo. Dal menu del blocco puoi ruotarla a sinistra/destra. Xcopy salva l’orientamento senza ricomprimere l’immagine originale.

Audio

Il pulsante Play diventa Stop durante la riproduzione e torna Play a fine traccia/errore. Avviare un secondo audio ferma il precedente.

Inserisci in Note dal file manager

Dal menu pressione lunga di un file scegli Inserisci in Note: testo → blocco testo; immagini → blocco immagine; audio → blocco audio; altri file → percorso/riferimento. Puoi creare una nuova nota o scegliere una esistente.

Esporta, condividi e backup

Le note possono essere esportate/condivise; il formato multimediale conserva l’ordine dei blocchi. I backup Xcopy includono le note e i media privati associati.
