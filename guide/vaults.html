Vaults

Create multiple independent encrypted spaces with separate passwords, biometrics and recovery codes.

On this pageCreating a vaultRecovery codePer-vault biometricsManagement

Creating a vault

Expand Vault and choose + New vault. Give it a name and set a strong password. Each vault is independent.

Recovery code

At creation Xcopy generates a recovery code to store outside the phone. It is not stored in plaintext. If you lose the password, use the code to set a new one.

Keep it safeIf you lose the password, recovery code and have no valid already-configured biometric key, there is no backdoor to decrypt the data.

Per-vault biometrics

Long-press a vault: the menu shows Enable biometrics or Disable biometrics for that vault only. Each profile uses separate state and Keystore keys.

Management

Long-press a vault to change its password, manage biometrics or password recovery, rename it, or delete it. To create another vault, use + New vault.

Cassaforti

Creare più spazi cifrati indipendenti con password, biometria e codice di recupero separati.

In questa paginaCreare una cassaforteCodice di recuperoBiometria per singola cassaforteGestione

Creare una cassaforte

Espandi Cassaforte e scegli + Nuova cassaforte. Dai un nome e imposta una password robusta. Ogni cassaforte è indipendente dalle altre.

Codice di recupero

Alla creazione Xcopy genera un codice di recupero da conservare fuori dal telefono. Non viene memorizzato in chiaro. Se perdi la password puoi usare questo codice per impostarne una nuova.

ConservazioneSe perdi password, codice di recupero e non hai una biometria valida già configurata, non esiste una backdoor per decifrare i dati.

Biometria per singola cassaforte

Tieni premuta una cassaforte: il menu mostra Abilita biometria o Disabilita biometria solo per quella cassaforte. Ogni profilo usa stato e chiavi Keystore separati.

Gestione

Tieni premuta una cassaforte per modificare la password, gestire la biometria o il recupero password, rinominarla oppure eliminarla. Per creare una nuova cassaforte usa + Nuova cassaforte.
