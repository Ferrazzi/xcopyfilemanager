Wi‑Fi file transfer

Share Xcopy files with a browser or another device on the same network.

On this pageStarting the serverBrowser pageStoppingSecurity

Starting the server

Enable Wi‑Fi transfer from the app menu, launcher shortcut or Quick Settings tile. While active, Android shows a foreground notification.

Browser page

Open the address shown by Xcopy on a device in the same LAN. The icon-based page supports multi-selection and can prepare a ZIP download for multiple items.

Stopping

Use the same toggle, Quick Settings tile or the notification action. Launcher shortcuts switch between Enable/Disable in Xcopy's selected language.

Security

Trusted networkUse sharing only on networks you control and configure available access protections. On a public LAN, other devices may be able to reach the service.

Trasferimento file Wi‑Fi

Condividere i file di Xcopy con un browser o un altro dispositivo sulla stessa rete.

In questa paginaAttivare il serverPagina browserDisattivareSicurezza

Attivare il server

Attiva il trasferimento Wi‑Fi dal menu dell’app, dal collegamento rapido dell’icona o dal riquadro Quick Settings. Quando il servizio è attivo Android mostra una notifica foreground.

Pagina browser

Apri l’indirizzo mostrato da Xcopy su un dispositivo nella stessa LAN. La pagina è progettata a icone, supporta selezioni multiple e può preparare un archivio ZIP per scaricare più elementi insieme.

Disattivare

Usa lo stesso toggle, il riquadro rapido o l’azione prevista nella notifica. Gli shortcut dell’icona cambiano tra Abilita/Disabilita nella lingua impostata dentro Xcopy.

Sicurezza

Rete fidataUsa la condivisione solo su reti che controlli e configura le opzioni di accesso disponibili. Una rete locale pubblica può esporre il servizio ad altri dispositivi presenti sulla stessa LAN.
