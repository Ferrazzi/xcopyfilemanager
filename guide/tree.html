Navigation tree

Use the tree to quickly reach local storage, network connections, cloud services, USB drives, vaults and other available sources.

On this pageMain nodesCustomize the treeLong press

Main nodes

NodePurpose
StorageFiles and folders stored on the device.
AppsInstalled and system apps. You can view the package name and, when allowed, copy the APK.
SMB / FTP / SSHSaved connections to computers, NAS devices and network servers.
Web archiveConfigured cloud services and other remote sources.
USBUSB storage connected to the device.
VaultEncrypted vaults created in Xcopy.
DLNAMedia servers available on the local network.
TrashDeleted items that can still be recovered.

Customize the tree

Each panel can have its own node order and visibility. Long-press a reorderable node and drag it to the position you prefer. Use the dedicated toolbar button to choose which nodes are shown or hidden.

Independent panelsChanges made to the left panel tree do not affect the right panel, and vice versa.

Long press

A long press opens the actions available for that node. For example, network connections can open their configuration; vaults provide security, biometrics, rename and delete options; reorderable nodes can be moved.

Albero di navigazione

Usa l’albero per raggiungere rapidamente memorie locali, connessioni di rete, cloud, USB, cassaforti e le altre sorgenti disponibili.

In questa paginaNodi principaliPersonalizzare l’alberoPressione lunga

Nodi principali

NodoUso
MemoriaFile e cartelle presenti sul dispositivo.
AppApplicazioni installate e di sistema. Puoi vedere il nome del pacchetto e, quando consentito, copiare l’APK.
SMB / FTP / SSHConnessioni salvate verso computer, NAS e server di rete.
Archivio WebServizi cloud e altre sorgenti remote configurate.
USBMemorie USB collegate al dispositivo.
CassaforteCassaforti cifrate create in Xcopy.
DLNAMedia server disponibili nella rete locale.
CestinoElementi eliminati che possono ancora essere recuperati.

Personalizzare l’albero

Ogni pannello può avere il proprio ordine e i propri nodi visibili. Tieni premuto un nodo riordinabile e trascinalo nella posizione che preferisci. Dal pulsante dedicato nella barra puoi scegliere quali nodi mostrare o nascondere.

Pannelli indipendentiLe modifiche fatte all’albero del pannello sinistro non cambiano quello del pannello destro, e viceversa.

Pressione lunga

La pressione lunga apre le azioni disponibili per quel nodo. Per esempio, sulle connessioni di rete puoi aprire la configurazione; sulle cassaforti puoi gestire sicurezza, biometria, nome ed eliminazione; sui nodi riordinabili puoi cambiarne la posizione.
