Shizuku and root

Advanced access to Android-restricted paths while keeping visual state tied to the real service state.

On this pageShizuku lockWhen it is usedAndroid limits

Shizuku lock

The toolbar lock reflects the real binder/permission state. Green means Shizuku is ready and authorized; red means unavailable/not authorized. Screen rotation should not falsify it.

When it is used

Xcopy can use privileged access for paths unavailable through the normal File API. Root and Shizuku are used only where configured/supported.

Android limits

Some restrictions are still enforced by Android/firmware. If a path cannot be accessed, Xcopy may fall back to SAF/DocumentProvider or show the actual error instead of pretending access.

Shizuku e root

Accesso avanzato ai percorsi che Android normalmente limita, senza confondere lo stato grafico con quello reale.

In questa paginaLucchetto ShizukuQuando serveLimiti Android

Lucchetto Shizuku

Il lucchetto della barra mostra lo stato reale del binder/permesso. Verde significa Shizuku disponibile e autorizzato; rosso significa non disponibile/non autorizzato. La rotazione dello schermo non deve falsare lo stato.

Quando serve

Xcopy può usare accesso privilegiato per operazioni su percorsi che la normale API File non consente. Root e Shizuku vengono usati solo dove configurati/supportati.

Limiti Android

Alcune restrizioni restano imposte dal sistema/firmware. Se un percorso non è accessibile, Xcopy può ricorrere a SAF/DocumentProvider o mostrare l’errore reale invece di simulare accesso.
