Time Machine

Automatic pre-change versions with retention limits, management and exclusions.

On this pageDefault stateConfigurationExclusionsManage and restore

Default state

Time Machine is off by default. Enable it in Settings only if you want Xcopy to save previous versions for configured operations.

Configuration

Configure retention, versions per item, storage limit, maximum item size and which operations create snapshots.

Exclusions

In Settings → Time Machine → Exclusions add files/folders to ignore. Excluding a folder also excludes all descendants, even when a parent folder is captured in a snapshot.

Manage and restore

Time Machine management lets you inspect versions, restore and protect important snapshots. Exclusions apply to future snapshots and do not automatically delete existing versions.

Time Machine

Versioni automatiche prima delle modifiche, con limiti, gestione ed esclusioni.

In questa paginaStato inizialeConfigurazioneEsclusioniGestire e ripristinare

Stato iniziale

Time Machine è disattivato di default. Abilitalo dalle Impostazioni solo se vuoi che Xcopy salvi versioni precedenti per le operazioni configurate.

Configurazione

Puoi impostare conservazione, numero di versioni, spazio massimo, dimensione massima degli elementi e quali operazioni generano snapshot.

Esclusioni

In Impostazioni → Time Machine → Esclusioni aggiungi file o cartelle da ignorare. Se escludi una cartella, vengono ignorati anche tutti i discendenti, perfino quando una cartella padre viene salvata in uno snapshot.

Gestire e ripristinare

La gestione Time Machine permette di vedere le versioni disponibili, ripristinare e proteggere versioni importanti. Le esclusioni valgono per gli snapshot futuri e non cancellano automaticamente versioni già esistenti.
