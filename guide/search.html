Search

Find items quickly in the current location using available filters.

On this pageStarting a searchScopeResults

Starting a search

Tap Search on the active panel toolbar. Enter text and use available options to restrict results to files/folders or include hidden items.

Scope

Scope depends on the current source. Deep searches on remote sources may require many network requests; Xcopy avoids unsupported protocol operations.

Results

Open a result or use compatible contextual actions. If content changes, run the search again for an updated result set.

Ricerca

Trova rapidamente elementi nella posizione corrente usando i filtri disponibili.

In questa paginaAvviare una ricercaAmbitoRisultati

Avviare una ricerca

Premi Cerca nella barra del pannello attivo. Inserisci il testo e scegli le opzioni disponibili per limitare il risultato a file/cartelle o includere elementi nascosti.

Ambito

L’ambito dipende dalla sorgente corrente. Su alcune sorgenti remote una ricerca profonda può richiedere molte richieste di rete; Xcopy evita operazioni non supportate dal protocollo.

Risultati

Apri un risultato o usa i menu contestuali compatibili. Se il contenuto cambia, rilancia la ricerca per avere un set aggiornato.
