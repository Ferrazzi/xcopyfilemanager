Vertical toolbar

Quick reference for commands available on the active panel.

On this pageNavigation commandsViewingOperations

Navigation commands

HomeReturns to the active panel root/tree.
UpMoves to the parent folder.
Shizuku lockGreen = Shizuku ready and authorized; red = unavailable/not authorized.
SearchSearches the current context with available filters.

Viewing

Show hiddenCrossed eye = hidden items are not shown; normal eye = hidden files and folders are visible.
SortSorts files by name, size, extension or date and handles folder order separately.
DetailsComputes recursive size and counts for the current selection.

Operations

Copy, Move, Duplicate, Rename, Delete, Share, ZIP and other buttons operate on the current selection when the source supports them. Long operations run with background handling and refresh affected panels.

Barra strumenti verticale

Riferimento rapido ai comandi sempre disponibili sul pannello attivo.

In questa paginaComandi di navigazioneVisualizzazioneOperazioni

Comandi di navigazione

HomeTorna alla radice/tree del pannello attivo.
SuSale alla cartella padre.
Lucchetto ShizukuVerde = Shizuku disponibile e autorizzato; rosso = non disponibile/non autorizzato.
CercaRicerca nel contesto corrente con le opzioni disponibili.

Visualizzazione

Mostra nascostiOcchio sbarrato = file nascosti non visibili; occhio normale = file e cartelle nascosti visibili.
OrdinaOrdina file per nome, dimensione, estensione o data e gestisce separatamente l’ordine delle cartelle.
DettagliCalcola dimensione ricorsiva e conteggi della selezione.

Operazioni

I comandi Copia, Sposta, Duplica, Rinomina, Elimina, Condividi, ZIP e gli altri pulsanti agiscono sulla selezione corrente quando l’origine lo consente. Le operazioni lunghe vengono eseguite con gestione in background e aggiornamento dei pannelli interessati.
