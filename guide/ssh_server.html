Built-in SSH/SFTP server

Encrypted SFTP file sharing configured directly from the tree.

On this pageSSH/SFTP Server nodeConfigurationClient connectionWhen to prefer it

SSH/SFTP Server node

Expand SSH in the tree. Tap SSH/SFTP Server to toggle; long-press to open configuration.

Configuration

Set port, username, password, root folder, read-only mode and auto-start. Credentials remain locally protected according to app security handling.

Client connection

From a PC or other device, use an SFTP client with the phone IP, configured port and Xcopy credentials.

When to prefer it

SFTP encrypts session, authentication and data, so it is preferable to FTP when the network is not fully trusted.

Server SSH/SFTP interno

Condivisione file cifrata tramite SFTP con configurazione dal tree.

In questa paginaNodo Server SSH/SFTPConfigurazioneConnessione clientQuando preferirlo

Nodo Server SSH/SFTP

Espandi SSH nel tree. Toccando Server SSH/SFTP lo attivi/disattivi; con pressione lunga apri la configurazione.

Configurazione

Imposta porta, utente, password, cartella radice, sola lettura e avvio automatico. Le credenziali rimangono protette localmente secondo la gestione sicurezza dell’app.

Connessione client

Da PC o altro dispositivo usa un client SFTP puntando all’IP del telefono, porta configurata e credenziali impostate in Xcopy.

Quando preferirlo

SFTP cifra sessione, autenticazione e dati ed è quindi preferibile a FTP quando la rete non è completamente fidata.
