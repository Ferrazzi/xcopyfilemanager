The two panels

Xcopy is a dual-panel file manager. The panel you touch becomes active; its current folder name is shown under Left panel or Right panel. The other panel remains the destination even when portrait layout cannot show both at the same time.

Practical ruleFirst navigate the destination panel to the desired folder, then return to the source panel, select items and use Copy or Move.

Selecting files and folders

Tap an item to open it. Use selection mode to mark multiple items; toolbar and long-press actions operate on the whole selection.

Without a multi-selection, contextual commands apply to the item you long-pressed.

Rotation and state

Both panels preserve independent path, tree, sorting and configuration. Screen rotation rebuilds the UI while retaining expected operational state, including Shizuku status.

I due pannelli

Xcopy è un file manager a doppio pannello. Il pannello che tocchi diventa quello attivo; il nome della cartella corrente appare sotto Pannello sinistro o Pannello destro. L’altro pannello rimane disponibile come destinazione anche quando, in verticale, non è visibile contemporaneamente.

Regola praticaPrima porta il pannello di destinazione nella cartella giusta, poi torna nel pannello sorgente, seleziona gli elementi ed esegui Copia o Sposta.

Selezionare file e cartelle

Tocca un elemento per aprirlo. Usa la selezione prevista dall’interfaccia per marcare più elementi; le operazioni della barra e del menu pressione lunga useranno l’intera selezione.

Se non c’è una selezione multipla, i comandi contestuali agiscono sull’elemento premuto.

Rotazione e stato

I due pannelli conservano percorso, tree, ordinamento e configurazioni indipendenti. Ruotando lo schermo Xcopy ricrea l’interfaccia senza perdere lo stato operativo previsto, compreso lo stato Shizuku.
