Privacy Policy

Informativa sulla privacy

Last updated: 12 September 2026

Ultimo aggiornamento: 12 settembre 2026

This Privacy Policy explains how Xcopy File Manager for Android accesses and handles information when you use the app. Xcopy is primarily an on-device file manager. It does not require an Xcopy account.

Questa informativa spiega come Xcopy File Manager per Android accede e gestisce le informazioni durante l'uso dell'app. Xcopy è principalmente un file manager che lavora sul dispositivo e non richiede un account Xcopy.

1. Local files and media

1. File e contenuti locali

Xcopy requests storage and media access only to provide file-management features requested by you, such as browsing, copying, moving, renaming, deleting, previewing and editing files. Local file contents are processed on the device unless you explicitly choose a remote destination or sharing feature.

Xcopy richiede l'accesso a memoria e contenuti multimediali esclusivamente per fornire le funzioni di gestione file richieste dall'utente, ad esempio navigazione, copia, spostamento, rinomina, eliminazione, anteprima e modifica. Il contenuto dei file locali viene elaborato sul dispositivo, salvo quando scegli esplicitamente una destinazione remota o una funzione di condivisione.

2. Network and remote connections

2. Connessioni di rete e remote

Xcopy can connect, at your request, to SMB/LAN, FTP, SFTP/SSH and WebDAV servers that you configure. Connection details are stored locally on the device. Saved connection passwords are protected using an app-private AES key held by Android Keystore. A manual settings backup can include supported network credentials only inside an encrypted backup protected by a password chosen by you; automatic backups do not include saved network passwords.

Xcopy può collegarsi, su tua richiesta, a server SMB/LAN, FTP, SFTP/SSH e WebDAV configurati da te. I dati delle connessioni sono memorizzati localmente sul dispositivo. Le password salvate sono protette con una chiave AES privata dell'app custodita da Android Keystore. Un backup manuale delle impostazioni può includere le credenziali di rete supportate solo all'interno di un backup cifrato protetto da una password scelta da te; i backup automatici non includono le password delle connessioni.

3. Google Drive

3. Google Drive

Google Drive integration is optional and starts only after you choose to connect a Google account. Xcopy requests the Google Drive scope needed to act as a file manager. This lets Xcopy, when you request it, list folders and files and perform operations such as download, upload, create, rename, move and delete.

L'integrazione con Google Drive è facoltativa e viene avviata solo quando scegli di collegare un Account Google. Xcopy richiede l'ambito Google Drive necessario per funzionare come file manager. Questo consente a Xcopy, su tua richiesta, di elencare cartelle e file e di eseguire operazioni come download, upload, creazione, rinomina, spostamento ed eliminazione.

  • Xcopy stores the selected Google account email/display name locally so the connection can be shown again in the app.
  • Google OAuth access tokens are kept in memory for the active authorization flow and are not intentionally persisted by Xcopy.
  • Google Drive file contents are transferred directly between your device and Google Drive, except when you explicitly direct Xcopy to copy or share a file to another destination you selected.
  • Xcopy does not sell Google user data and does not use Google Drive file content for advertising, ad targeting, credit decisions, or training general-purpose AI models.
  • Xcopy does not provide developer personnel with routine access to your Google Drive file content.
  • Xcopy salva localmente l'indirizzo email/nome visualizzato dell'Account Google selezionato, in modo da poter mostrare nuovamente la connessione nell'app.
  • I token di accesso OAuth di Google vengono mantenuti in memoria per il flusso di autorizzazione attivo e non vengono intenzionalmente salvati in modo persistente da Xcopy.
  • Il contenuto dei file Google Drive viene trasferito direttamente tra il dispositivo e Google Drive, salvo quando chiedi esplicitamente a Xcopy di copiare o condividere un file verso un'altra destinazione da te scelta.
  • Xcopy non vende i dati utente Google e non usa il contenuto dei file Drive per pubblicità, targeting pubblicitario, decisioni creditizie o addestramento di modelli di IA general-purpose.
  • Xcopy non prevede un accesso ordinario del personale dello sviluppatore al contenuto dei file Google Drive.

Google Limited Use disclosure. Xcopy File Manager uses information obtained through Google APIs in accordance with the Google API Services User Data Policy and its Limited Use requirements.

Dichiarazione Google Limited Use. Xcopy File Manager utilizza le informazioni ottenute tramite le API Google nel rispetto della Google API Services User Data Policy e dei relativi requisiti Limited Use.

4. Advertising

4. Pubblicità

The free version of Xcopy uses Google Mobile Ads (AdMob). The Google Mobile Ads SDK may process information such as device or app identifiers, IP address (which can be used to estimate approximate location), app interactions and diagnostic information for advertising, analytics and fraud-prevention purposes. Xcopy does not provide Google Drive file content to AdMob.

La versione gratuita di Xcopy utilizza Google Mobile Ads (AdMob). L'SDK Google Mobile Ads può trattare informazioni quali identificatori del dispositivo o dell'app, indirizzo IP (che può essere usato per stimare la posizione approssimativa), interazioni con l'app e informazioni diagnostiche per finalità pubblicitarie, di analisi e prevenzione delle frodi. Xcopy non fornisce ad AdMob il contenuto dei file Google Drive.

5. Purchases

5. Acquisti

Xcopy uses Google Play Billing for in-app purchases. Payment processing is handled by Google Play. Xcopy uses the purchase result to determine whether paid features are enabled and does not operate its own payment-card processing service.

Xcopy utilizza Google Play Billing per gli acquisti in-app. L'elaborazione dei pagamenti è gestita da Google Play. Xcopy usa il risultato dell'acquisto per determinare se le funzioni a pagamento sono abilitate e non gestisce un proprio servizio di elaborazione delle carte di pagamento.

6. Vaults and app security

6. Cassaforti e sicurezza dell'app

Vault contents are encrypted locally. Vault passwords or recovery secrets are not included in normal settings backups. Optional biometric access relies on Android's secure biometric/Keystore mechanisms.

Il contenuto delle Cassaforti viene cifrato localmente. Le password o le informazioni di recupero delle Cassaforti non vengono incluse nei normali backup delle impostazioni. L'accesso biometrico opzionale utilizza i meccanismi sicuri di Android per biometria e Keystore.

7. Data retention and deletion

7. Conservazione ed eliminazione dei dati

Most Xcopy configuration data is stored locally on your device and can be removed by deleting connections, clearing app data or uninstalling the app. You can disconnect a Google Drive account from Xcopy and revoke Google's authorization from your Google Account security settings. Files stored on remote services remain governed by the destination service and by actions you request.

La maggior parte dei dati di configurazione di Xcopy è memorizzata localmente sul dispositivo e può essere rimossa eliminando le connessioni, cancellando i dati dell'app o disinstallando l'app. Puoi scollegare un account Google Drive da Xcopy e revocare l'autorizzazione Google dalle impostazioni di sicurezza del tuo Account Google. I file presenti sui servizi remoti restano soggetti alle regole del servizio di destinazione e alle operazioni richieste dall'utente.

8. Security and transport

8. Sicurezza e trasporto

Xcopy supports both encrypted and, where explicitly configured by the user, legacy unencrypted network protocols. For sensitive transfers, use encrypted transports such as SFTP/SSH or HTTPS/WebDAV over TLS. The security of a remote destination you configure is also determined by that destination and its settings.

Xcopy supporta sia protocolli di rete cifrati sia, quando configurati esplicitamente dall'utente, protocolli legacy non cifrati. Per trasferimenti sensibili è consigliato utilizzare trasporti cifrati come SFTP/SSH o HTTPS/WebDAV su TLS. La sicurezza di una destinazione remota configurata dall'utente dipende anche dal servizio e dalle impostazioni della destinazione stessa.

9. Children

9. Minori

Xcopy is a general-purpose file-management utility and is not designed specifically for children.

Xcopy è un'utilità generale per la gestione dei file e non è progettato specificamente per i minori.

10. Modifiche

Questa informativa può essere aggiornata quando cambiano le funzioni di Xcopy, gli SDK utilizzati o i requisiti applicabili. La versione corrente sarà sempre pubblicata su questa pagina.
